# دليل البدء السريع — زميل نيوتك الذكي

## ما هو؟
زملاء ذكاء اصطناعي يعملون داخل ERPNext. لكل زميل دور وأدوات مصرّح بها، ويعمل بصلاحيات المستخدم نفسه فقط.
كل إجراء يُفحص وفق سياسة الشركة ويُسجَّل في سجل تدقيق قبل تنفيذه.

## التثبيت (Frappe Cloud)
1. أضف التطبيق من GitHub إلى مجموعة الخوادم (Bench Group) ثم نفّذ النشر (Deploy).
2. ثبّت التطبيق على الموقع.
3. افتح ‎/app/coworker-setup‎ واتبع الخطوات الأربع:
   - ربط مزوّد الذكاء الاصطناعي واختبار الاتصال.
   - اختيار الزملاء.
   - الحوكمة: وضع إقامة البيانات، إخفاء البيانات الشخصية، الاعتمادات، ومنح الصلاحيات.
   - فحص الجاهزية.

## الاستخدام
- افتح ‎/app/coworker‎ واختر زميلاً، أو اضغط **اسأل الزميل** من أي مستند.
- الاختصار: Ctrl+Shift+K.
- اكتب بالعربية أو الإنجليزية؛ يرد الزميل بلغة سؤالك.
- عند طلب تغيير بيانات تظهر بطاقة **يتطلب اعتماداً**؛ اضغط **اعتماد وتنفيذ** أو **رفض**.
- زر **النشاط** يعرض كل أداة استُخدمت والقاعدة التي طُبّقت.

## الحماية وفق نظام حماية البيانات الشخصية
- **الوضع المحروس**: لا تُرسَل بيانات الموظفين والرواتب والحسابات البنكية إلى مزوّد خارجي.
- **الوضع الصارم**: يُمنع استخدام أي مزوّد خارجي.
- تُخفى أرقام الهوية والإقامة والآيبان والبطاقات والجوال والبريد قبل إرسالها لمزوّد خارجي.

## أدوات خاصة بالمملكة
- حاسبة ضريبة القيمة المضافة (15%).
- التحقق من الرقم الضريبي والآيبان مع اسم البنك.
- مكافأة نهاية الخدمة وفق المواد 84 و85 و87 و80 من نظام العمل.
- فحص جاهزية الفاتورة للفوترة الإلكترونية.

> النتائج تقديرية؛ يُرجى التحقق من الأنظمة السارية ومن تطبيق الفوترة الإلكترونية المعتمد.
